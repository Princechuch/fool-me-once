# Fool Me Once

Playtest version 0.4 (18 November 2026) of two card games for the family table about the tricks used to sell to you and persuade you online.

- **The Guru:** one player secretly slips a trick into the conversation; the rest catch who and name the trick.
- **The Pitch:** sell the table something ridiculous using a real trick; the rest name it.

Files:
- `index.html`: both games, one phone on the table (English and Spanish).
- `print.html?lang=en` / `?lang=es`: print-and-play sheets.
- `cards.js`: tricks and topics. `extra.js`: trick packs, examples, "not the same as" lines, and The Pitch's products and buyers.
- `manual.js`: the manual of each game, Spot the box and the family playtest kit. `print.html?only=docs&lang=es` prints just the manuals and the kit.
