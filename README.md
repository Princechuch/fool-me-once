# Fool Me Once · The Guru

Playtest version 0.1 of a card game for the family table. One player is secretly the Guru and slips a persuasion trick into the conversation; everyone else catches who it is and names the trick.

- `index.html`: the game, one phone on the table (English and Spanish).
- `print.html?lang=en` / `?lang=es`: print-and-play sheets.
- `cards.js`: the 25 tricks and 40 topics, one source for both.
